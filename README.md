# Kairos for Homebrew

Air traffic control for your coding agents.

```bash
brew install --cask matih-labs/tap/kairos
```

Kairos for Mac (macOS 15 or later, Apple silicon and Intel) watches every
coding session on your Mac, whichever tool runs it, and knows what each
account has left. It keeps itself up to date, so `brew upgrade` leaves it to
Kairos. `brew uninstall --cask kairos` does what Kairos's Settings > Remove
Kairos… does: its background items and files go; your accounts and their
sign-ins stay.

More at [kairos.matihlabs.com](https://kairos.matihlabs.com). Kairos's
releases write `Casks/kairos.rb` here.
